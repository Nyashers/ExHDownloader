# ExHDownloader
![PreviewScript](https://raw.githubusercontent.com/Nyashers/ExHDownloader/refs/heads/main/image/ExH%20Downloader%20preview.png)
Little script for downloading original and scaled pictures on ExH
<hr size="5">

## Features

- Ability to open images in a new tab instead of the current page;
- Download a single image or all images at once;
- View the image request limit (updates every 1 minute);
- Download the original image size (if available on your E-Hentai account);
- Automatically fallback to downloading the sample image if the original is unavailable.
